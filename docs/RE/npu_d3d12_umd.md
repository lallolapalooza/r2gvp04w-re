## Role
**D3D12 user-mode driver (UMD)** for Intel NPU — the DLL Windows loads into a D3D12
client process. Single export `OpenAdapter12` implements the D3D12 UMD entry contract.

## Architecture (RTTI-derived)
Templated over **per-platform AdapterTraits** under namespace `SHASTA`:
- `D3D12::KMB::AdapterTraits` (Knob Lake/Meteor-refresh?),
- `D3D12::LNL::AdapterTraits` (Lunar Lake),
- `D3D12::MTL::AdapterTraits` (Meteor Lake)

Per-trait instantiation of:
- `Resource<>` (D3D10DDI_HRESOURCE-based GPU resource object)
- `gpu_allocator<>` / `cpu_allocator<>` / `cmx_allocator<>` (CMX = NPU on-chip shared memory)
- `metacommand<>` (`D3D12DDI_HMETACOMMAND_0052`) — D3D12 **MetaCommand** DDI: the path by
  which D3D12 expresses NPU workloads (e.g. DirectML-style inference)

  `SHASTA::error_report<AdapterTraits>::submit` → **Windows WER** (`WerReportCreate/AddDump/Submit`)

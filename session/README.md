# Session archives

Exports of the working sessions for this reverse-engineering project, produced
with the [`omp-archive`](https://github.com/alosslessdev/omp-archive-main) plugin.

| File | Contents |
|---|---|
| `omp-session-archive.zip` | main session export: `manifest.json`, `session.jsonl`, untruncated artifact logs, `viewer.html` |
| `omp-npu-chats.zip` | bundle of earlier archives, grouped by topic (`other-npu/`, `touching-folders/`), plus their READMEs |

Both are also published as release assets on
<https://github.com/lallolapalooza/r2gvp04w-re/releases/tag/omp-session-archive>.
